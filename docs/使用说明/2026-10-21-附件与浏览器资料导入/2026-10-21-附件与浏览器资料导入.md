# 附件与浏览器资料导入

## 对话输入框入口

点击对话工作台输入框左下角的回形针图标，选择附件类型。尚未建立需求对话时也可以导入。

| 入口 | 文件 | 导入结果 |
| --- | --- | --- |
| 需求文档 | PDF、DOCX、XLSX、PPTX、TXT、Markdown、CSV、TSV、HTML、JSON | 加入文档库，在文档分析中预览和生成分析；不会自动调用模型 |
| 浏览器书签 | 浏览器导出的 HTML / HTM | 保留标题、网址和文件夹，可搜索并在顶部网页标签打开 |
| 浏览器密码 | 浏览器导出的 CSV | 账号和密码经系统安全存储加密后保存，按网站匹配填入 |
| 查看书签与密码 | 无需文件 | 查看、搜索、移除已导入的资料 |

导入结果在输入框附近显示新增、重复、无效记录数量。取消文件选择不写入数据；导入密码不创建聊天消息、模型附件或文档记录。资料管理窗口也可以导入，网页地址栏右侧的书签按钮和密码按钮可直接打开该窗口。

## 从已有浏览器迁移

先使用原浏览器的导出功能取得文件，再通过附件按钮选择该文件。Chrome 的书签管理器可导出 HTML，密码管理器的设置中可导出密码文件，参见 [Chrome 书签导出说明](https://support.google.com/chrome/answer/96816) 和 [Chrome 密码管理说明](https://support.google.com/chrome/answer/95606)。Safari 的书签 HTML 与密码 CSV 格式参见 [Apple 导出数据说明](https://developer.apple.com/documentation/SafariServices/importing-data-exported-from-safari)。

支持 Chrome、Edge、Firefox、Safari 常用的书签 HTML 和密码 CSV。密码 CSV 必须包含网址、用户名、密码列，识别 `url`、`username`、`password` 等常用表头及大小写差异。支持 UTF-8（可带 BOM）及带 BOM 的 UTF-16，保留密码中的逗号、引号、换行及前后空格。Safari 的 Notes、OTPAuth 等附加列不导入；通行密钥、验证码种子、浏览历史和 Cookie 不在此导入范围内。Safari 导出若为压缩包，请先解压后选择其中的 HTML 或 CSV。

每个浏览器资料文件最多 10 MB、10,000 条记录。书签按「网址 + 文件夹」去重；密码按「完整网站来源 + 用户名」去重，重复时保留已有密码，不覆盖。需要更新密码时先在管理窗口移除对应记录，再重新导入。无效网址、空密码及无效行会跳过并报告数量；文件格式错误或加密失败时不写入本次数据。

## 使用密码登录

1. 从书签、任务或对话中的链接打开登录网页。
2. 点击地址栏右侧「密码」，选择属于当前网站的账号。
3. 点击「填入登录页」，关闭资料窗口，然后在网页中确认并登录。

仅在协议、域名、端口全部匹配时填入，不自动扩展到子域名，也不自动提交表单。页面正在加载或任务正在执行时不会填入。页面跳转、跨站表单、多密码框、注册/改密页、iframe 登录页等场景提示手动处理。账号展示为掩码，密码始终显示星号，不提供明文查看或复制接口。

导入数据保存到当前 SQLite 数据库，随自定义数据库目录迁移；密码解密依赖当前系统用户的安全存储，复制数据库到其他机器不保证可解密。原 CSV 含明文密码，导入后需妥善保管或自行删除。应用不直接读取 Chrome/Edge/Safari 的受保护密码库。

## 验证范围

- 自动化回归覆盖：文件格式、书签目录、CSV 转义和编码、导入限制、重复记录、失败回滚、加密保存、迁移与重启读取，以及跨站/跳转/改密表单的填入限制。
- macOS 桌面联调使用独立测试资料目录与本机测试网站，验证附件入口、系统文件选择、实际导入、书签打开和密码填入；不使用用户的真实密码文件。
- Windows 使用同一文件解析、数据库和 Electron 界面实现，仍需 Windows 实机验证系统文件选择及安全存储。
