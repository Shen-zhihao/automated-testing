# 自动化测试 Agent 原型

日期：2026-10-20（北京时间）

## 运行方式

产品目标平台为 Windows 和 macOS。桌面原型使用 Electron 加载 React UI，正常启动直接读取本地构建资源，无需常驻 Web 服务，不需要 Python、数据库服务器或容器。飞书使用应用身份读取，无需登录或监听回调端口。

开发环境需要 Node.js 22.16+ 和 pnpm（仓库固定 9.15.9）。首次安装与启动时需要下载开发工具和 Electron；这不是应用运行时的联网数据库依赖。

以下命令在 Windows PowerShell / macOS 终端均可执行：

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm dev:desktop
```

开发模式会启动仅监听 `127.0.0.1:5180` 的 Vite 和桌面窗口，退出应用或在终端按 Ctrl+C 时一并关闭开发服务器。macOS 关闭窗口后应用按系统习惯继续驻留；完全退出使用 Cmd+Q。

验证本地构建运行方式：

```bash
cd frontend
pnpm desktop
```

此命令先构建 UI，再通过 `test-agent://app/index.html` 自定义协议加载本地资源，无需 Vite 或 Python 进程。在仓库中运行仍使用 Electron 开发依赖；最终安装包会包含桌面运行时。

开发数据目录和正常运行数据目录分别命名为 `Test Agent Development` 与 `Test Agent`，避免混用。

## 当前功能与边界

- 文档分析：本地文档提取、以应用身份导入飞书链接、原文预览、真实模型调用、长文分段分析、取消与结果复制。
- 设置：模型服务地址、接口格式、模型、加密 API Key、输出限制、温度、超时、连接测试；飞书 App ID、App Secret 和测试连接，测试成功自动保存。
- 对话工作台：基于需求快照与分析结果持续讨论，查看原文引用，选择回复保留到测试任务。
- 技能面板：搜索和查看示例模板。
- 测试任务：关联需求与讨论结论，生成详细测试文档和结构化用例，审阅执行计划，在内置浏览器执行并记录实际断言结果。
- 浏览器能力：从任务或文档/对话中的链接按需打开网页，固定到客户端顶部标签栏。直接在网页内登录，Cookie 与网站数据自动管理；关闭标签不取消任务。
- 桌面外壳：Windows / macOS 窗口生命周期、单实例、受限导航和本地资源加载。

文档、分析、设置、会话、测试任务和执行记录保存在 SQLite 中，重启后保留。测试文档生成与实际执行分开记录，未执行或需人工核验的内容不会标记为通过。操作流程见 [测试任务与内置浏览器](../2026-10-20-测试任务与内置浏览器/2026-10-20-测试任务与内置浏览器.md)。详细操作见 [文档分析与模型设置](../2026-10-20-文档分析与模型设置/2026-10-20-文档分析与模型设置.md)。

## 检查

```bash
cd frontend
pnpm typecheck
pnpm format:check
pnpm test
pnpm build
```

桌面主进程使用 JavaScript，`typecheck` 对它执行语法检查；React 和共享包执行 TypeScript 检查。测试覆盖文档格式、SQLite 重开、配置保护、模型请求、分段汇总、取消及已有原型行为。Windows 路径单元测试不代表已在 Windows 实机运行。

可选 Python 模块：

```bash
cd backend
poetry install
poetry run ruff check .
poetry run pytest -q
```

## 手动打包

在对应平台的开发机器上执行：

```bash
cd frontend
# macOS：DMG，arm64 / x64
pnpm package:mac
# Windows：NSIS 安装包，x64
pnpm package:win
```

命令只构建本地安装包，不上传发布。正式分发前仍需配置对应平台的应用图标、签名与公证，并在目标系统上测试。本次原型调整没有交付安装包，不包含 Python 执行模块，也未启用自动更新。

## 本地持久化

采用 SQLite 本地文件，位置按 Electron `app.getPath('userData')` 解析，存放到其 `storage/test-agent.sqlite` 子路径。当前保存文档文字、格式预览、分析、模型配置、需求快照、会话、任务、测试文档、执行记录。模型和飞书密钥先经 safeStorage 加密，文档文字本身未做数据库加密。可在设置中更改数据库保存目录。

浏览器 Cookie 等站点数据保存在 Electron 用户目录下的持久化分区，不随数据库目录迁移。React 通过受限的 preload / IPC 调用访问数据，不直接执行 SQL 或接触操作系统能力。详细职责见 [本地桌面架构](../../设计方案/2026-10-20-本地桌面应用架构/2026-10-20-本地桌面应用架构.md)。
