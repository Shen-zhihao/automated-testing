# Test Agent

面向 **Windows / macOS** 的本地自动化测试 Agent，采用 Electron + React + SQLite。以工程为工作单元，包含工程概览、需求分析、对话管理、测试验收、命令执行和文件清理。支持跟随系统、手动浅色或深色外观，选择后立即生效并保留到下次启动。支持常用文档导入、配置 App ID / App Secret 后以飞书应用身份读取已授权文档，以及调用用户配置的模型将需求拆分为功能实现步骤和验收标准，支持 Markdown 预览、复制和另存为 `.md`；对话工作台可结合需求持续讨论，把结论保留到测试任务，生成详细测试文档。Agent 按需在顶部网页标签中打开浏览器，直接在网页内登录，并执行审阅后的网页测试步骤；关闭网页标签不影响后台测试。

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm dev:desktop
```

加载构建后的本地 UI（无需启动开发服务器）：

```bash
pnpm desktop
```

不使用容器、远程数据库或云部署。文档、格式预览、分析结果和配置保存在本机，可在设置中更改保存目录并迁移已有数据，API Key 使用系统安全存储加密。对话、测试任务、用例与执行记录也在本机持久化。浏览器按工程隔离 Cookie、缓存与网站登录状态。工程命令使用系统 Shell，可选择逐条手动确认或完全托管；执行记录与工作目录纳入工程清理。智能体仅处理当前工程相关的需求、实现、测试与验收请求。对话输入框左下角的附件按钮支持导入需求文档、书签 HTML 和密码 CSV；导入密码加密保存在本机，可按网站选择填入，不发送给模型。开发环境需要 Node.js 22.16+。
